# Замкни цепь!

Casual puzzle для браузеров: игрок поворачивает элементы электрической схемы, чтобы подать питание от генератора ко всем лампам.

## Репозитории

- Production protocols: https://github.com/AndrewStartcev/starcev-games-protocols
- Game repo: https://github.com/AndrewStartcev/-lose-the-circuit
- Protocol version: `1.0.0`
- Engine target: `Godot 4.7.2-stable`

## Статус

Сейчас проект находится на этапе **Intake / pre-production**. Код и production assets ещё не создаются до фиксации core loop, graybox и реальных UI-слотов.

## Важно про визуальные референсы

Приложенные к задаче изображения — **визуализации направления**, а не источник истины. Они задают атмосферу, палитру, плотность интерфейса и общий характер игры. Точная компоновка, размеры, набор UI-элементов, экономика и отдельные механики определяются GDD, graybox и `docs/ASSET_MANIFEST.md`.

Основные документы проекта находятся в `docs/`.
