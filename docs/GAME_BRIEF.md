## One-line pitch

> Поворачивай элементы электрической сети, замыкай цепь от генератора и зажигай все лампы.

## Player fantasy

Игрок чувствует себя мастером, который быстро «оживляет» запутанную электросеть. Главное удовольствие — визуально наблюдать, как после правильного поворота ток пробегает по собранной цепи и лампы загораются одна за другой.

## Core loop

1. Игрок видит сетку с генератором, проводниками и лампами.
2. Клик/тап по поворачиваемой плитке вращает её на 90°.
3. После каждого хода сеть пересчитывается от источника, подключённые участки подсвечиваются энергией.
4. Когда все лампы получают питание — уровень завершён, сохраняется лучший результат и открывается следующий.

## First 30 seconds

- Загрузка → минимальный главный экран → `Играть/Продолжить`.
- Первый уровень содержит одну лампу и 2–3 поворачиваемых элемента.
- Первая подсказка прямо на поле: `Нажми на плитку, чтобы повернуть`.
- После первого правильного соединения ток сразу визуально проходит по линии.
- Первая победа должна случиться примерно за 10–20 секунд без длинного tutorial.
- Первые уровни не прерываются fullscreen-рекламой: игрок сначала должен понять игру.

## Session / progression

- **1 minute:** игрок понимает вращение и проходит 1–2 простых уровня.
- **5 minutes:** появляются углы, T-образные соединения и несколько ламп.
- **15 minutes:** более плотные схемы, ложные направления, сложнее читать сеть.
- **30 minutes:** игрок находится в основной сложности 5×5 / 6×5 / 6×6 и улучшает результаты.
- **Reason to return:** продолжить линейку уровней, улучшать best moves. Daily puzzle — post-release кандидат.

## Controls

### Desktop

- ЛКМ по поворачиваемой плитке → поворот на 90° по часовой стрелке.
- Hover — только визуальный feedback.
- `Esc` → пауза.
- Опционально `R` → restart после подтверждения.

### Mobile

- Tap по плитке → поворот на 90°.
- Touch-friendly hit areas.
- Landscape; при portrait допустим понятный rotate-device overlay.

## Monetization hypothesis — Pikabu first

Цель — использовать больше рекламных возможностей Пикабу, но не превращать игру в рекламный спам и не ухудшать retention.

### Preloader

- На mobile использовать Pikabu Preloader один раз до `gameStarted()`, только если SDK сообщает поддержку.
- Он не должен искусственно задерживать загрузку игры.

### Rewarded

Rewarded — основной добровольный формат.

1. **Подсказка ×1** — исправить одну неверно ориентированную плитку.
2. **Сильная подсказка ×3** — исправить до трёх неверных плиток; показывать как отдельное более ценное предложение, а не автоматически после каждого хода.
3. **Получить дополнительную подсказку** — на result/menu при нулевом/низком запасе hints игрок может добровольно посмотреть рекламу и получить hint credit.

Правила:

- награда только при подтверждённом `reward == true`;
- если реклама недоступна/adblock — core loop полностью работает;
- rewarded CTA не должен маскироваться под обычную кнопку;
- после rewarded fullscreen сразу не показывать.

### Fullscreen

Fullscreen opportunity возникает на каждом естественном переходе `уровень завершён → следующий уровень`, но реальный показ решает централизованный AdsService.

Gate v1:

- первые 2 уровня — без fullscreen;
- первый fullscreen не раньше чем после ~120 секунд игровой сессии;
- далее не чаще одного фактического fullscreen impression в 120 секунд;
- показывать только после завершения уровня/перед следующим уровнем;
- если недавно был rewarded — suppress fullscreen минимум на 60 секунд;
- если `canShow() == false`, переход продолжается без задержки;
- никакой рекламы в середине puzzle/input/energy animation.

Это намеренно более монетизированная схема, чем «редко между уровнями», но остаётся внутри естественных пауз и platform cooldown.

## Content scope v1

- 50 детерминированных уровней.
- Размеры поля от 4×4 до максимум 6×6.
- Типы: straight, corner, T, cross, source, lamp, empty/blocker.
- 3 tutorial-уровня.
- Сохранение прогресса и best moves.
- 1 основной industrial-electric visual theme.
- Меню, gameplay, pause, settings, result.
- 3 rewarded сценария.
- Pikabu mobile preloader при поддержке.
- Fullscreen на natural breaks через AdsService gate.
- Pikabu SDK + cloud save через platform abstraction.
- Local fallback для разработки и тестов без SDK.

## Explicit non-goals v1

- Нет Yandex Games integration в текущем релизе.
- Нет обязательной валюты/магазина.
- Нет энергии/жизней.
- Нет PvP/социальной механики.
- Нет нескольких визуальных миров до проверки метрик.
- Нет runtime procedural generation как обязательной части gameplay.
- Нет portrait gameplay.
- Реклама не блокирует прогресс.

## Decision

`GO → CORE LOOP PROTOTYPE → PIKABU-FIRST RELEASE`

Главный риск — качество visual integration и корректный lifecycle рекламы/сохранений. Изображения из постановки остаются только art-direction references, а не точной спецификацией UI или ассетов.
