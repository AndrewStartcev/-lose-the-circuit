## One-line pitch

> Поворачивай элементы электрической сети, замыкай цепь от генератора и зажигай все лампы.

## Player fantasy

Игрок чувствует себя мастером, который быстро «оживляет» запутанную электросеть. Главное удовольствие — визуально наблюдать, как после правильного поворота ток пробегает по собранной цепи и лампы загораются одна за другой.

## Core loop

1. Игрок видит сетку с генератором, трубами/проводниками и лампами.
2. Клик/тап по поворачиваемой плитке вращает её на 90°.
3. После каждого хода сеть пересчитывается от источника, подключённые участки подсвечиваются энергией.
4. Когда все лампы получают питание — уровень завершён, сохраняется лучший результат и открывается следующий.

## First 30 seconds

- Загрузка → минимальный главный экран → `Играть/Продолжить`.
- Первый уровень содержит одну лампу и 2–3 поворачиваемых элемента.
- Первая подсказка показывается прямо на поле: «Нажми на плитку, чтобы повернуть».
- После первого правильного соединения ток сразу визуально проходит по линии.
- Первая победа должна случиться примерно за 10–20 секунд без чтения длинного tutorial.

## Session / progression

- **1 minute:** игрок понимает вращение и проходит 1–2 простых уровня.
- **5 minutes:** появляются углы, T-образные соединения и несколько ламп.
- **15 minutes:** более плотные схемы, ложные направления, сложнее читать сеть.
- **30 minutes:** игрок находится в основной сложности 5×5 / 6×5 / 6×6 и улучшает результаты.
- **Reason to return:** продолжить незавершённую линейку уровней, улучшить лучший ход/результат. Daily puzzle — возможное post-release расширение, не обязательное для v1.

## Controls

### Desktop

- ЛКМ по поворачиваемой плитке → поворот на 90° по часовой стрелке.
- Hover — только визуальный feedback, не обязательная механика.
- `Esc` → пауза.
- Опционально `R` → restart уровня после подтверждения.

### Mobile

- Tap по плитке → поворот на 90°.
- Все важные controls имеют touch-friendly hit area.
- Landscape; при portrait показывается понятный overlay с просьбой повернуть устройство, если это требуется платформенным layout.

## Monetization hypothesis

### Rewarded

1. **Подсказка:** исправить одну неверно ориентированную плитку в сторону сохранённого корректного решения.
2. **Усиленная подсказка:** исправить до 3 плиток за один просмотр, если обычные подсказки закончились или игрок явно запросил помощь.

Rewarded всегда добровольный. Если реклама недоступна — игра не блокируется.

### Fullscreen

- Только после завершения уровня, перед переходом к следующему.
- Не после каждого уровня: cadence/cooldown конфигурируется отдельно после теста.
- Никогда не показывать во время вращения/анимации сети.

## Content scope v1

- 50 детерминированных уровней.
- Размеры поля от 4×4 до максимум 6×6.
- Типы: straight, corner, T, cross, source, lamp, empty/blocker.
- 3 tutorial-уровня.
- Сохранение прогресса и best moves.
- 1 основной industrial-electric visual theme.
- Меню, gameplay, pause, settings, result.
- 2 rewarded сценария.
- Fullscreen между уровнями по cooldown.
- Яндекс + Пикабу через platform abstraction.

## Explicit non-goals v1

- Нет обязательной валюты/магазина.
- Нет энергии/жизней.
- Нет backend.
- Нет PvP/социальной механики.
- Нет нескольких визуальных миров/глав до проверки метрик.
- Нет runtime procedural generation как обязательной части gameplay.
- Нет portrait gameplay.

## Decision

`GO → CORE LOOP PROTOTYPE`

Причина: низкий технологический риск, сильная совместимость desktop/mobile, дешевая графическая система, понятная монетизация через подсказки и естественные точки fullscreen.

Главный риск — не механика, а качество visual integration: трубы обязаны соединяться идеально, а реальный экран не должен выглядеть хуже концепта.
